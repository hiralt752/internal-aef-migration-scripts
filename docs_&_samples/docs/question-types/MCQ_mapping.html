0. MCQ Key Transformation Rules

0.1 Type Mapping

Legacy type→ API type→ API subTypeNotes
MULTIPLE_CHOICE MULTIPLE_CHOICE TEXT (auto-detected, see §0.2) Standard single-answer MCQ.
MULTIPLE_SELECTION MULTIPLE_CHOICE TEXT (auto-detected, see §0.2) Multi-answer MCQ. Sets responseDeclaration.multipleAnswer = true.

0.2 SubType Detection

Computed by inspecting all options (body.choices.choiceItems[].answer) after extracting media from their HTML. Builds three boolean flags, then applies a decision table.

Step 1 — Guard: If body.choices.choiceItems is empty or missing → return "TEXT" immediately.
Step 2 — Per option loop: Parse each option's answer HTML to extract media and clean text.
  • textContent = non-empty text remains after cleaning.
  • imageContent = a non-math <img> was present in the option.
Step 3 — Accumulate flags across all options:
  • hasAnyImage = true if at least one option has an image.
  • hasAnyText = true if at least one option has non-empty text.
  • allArePureImages = true only if every option has an image AND no text.
Step 4 — Apply decision table:
hasAnyImageallArePureImageshasAnyText→ subTypeExample scenario
truetruefalse (implied) IMAGE All options are <img> tags only — no text label on any.
truefalsetrue IMAGE_TEXT Mixed: some options have image + text, or some are image-only while others are text-only.
falsefalseany TEXT No option contains any image — all are plain text (fallthrough / default).
allArePureImages edge case: An option that has an image but also has leftover text (even whitespace that survives HTML cleaning) breaks allArePureImages and pushes the result toward IMAGE_TEXT instead of IMAGE.
Available MCQ subType values: TEXT, IMAGE, IMAGE_TEXT, SPLIT_SCREEN, SPLIT_IMAGE, SPLIT_VIDEO, SPLIT_TEXT. The SPLIT variants are never auto-assigned during migration.
