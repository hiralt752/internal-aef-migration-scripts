0. Key Transformation Rules

0.1 Type & SubType

Legacy type→ API type→ API subTypeNotes
SELECT_A_BLANK DROPDOWN DROPDOWN_SENTENCE (hardcoded) Type is remapped. SubType always hardcoded to DROPDOWN_SENTENCE for migration. Other available values: SPLIT_SCREEN, CARDS — never assigned.

0.2 body.blanks Structure — key difference from FIB and DnD

Dropdown body.blanks is an object, not an array. FIB and DnD have body.blanks as a flat array of blank definitions. Dropdown wraps it differently — each blank carries its own choices inline.
FieldFIB/DnD sourceDropdown source
Shuffle flagbody.choices.shufflebody.blanks.shuffle
Blank definitionsbody.blanks[] (flat array)body.blanks.blankItems[]
Per-blank choicesbody.choices.choiceItems[] (global pool)body.blanks.blankItems[].choices[] (per-blank)
Per-blank choices: Unlike DnD where all options are a global pool shared across all blanks, Dropdown gives each blank its own independent set of choices. Each QB DropdownItemResource (blank) contains its own options[] array sourced from that blank's choices[].

0.3 Prompt Processing — sentence & @_@ replacement

Same approach as FIB and DnD — the full body.prompt HTML goes into sentence.text with each <blank-field> replaced by @_@. statement is always null.

Step 1 — Find all blank-field tags: Scan body.prompt for all <blank-field id="N" ...></blank-field> in DOM order.
Step 2 — Replace each with @_@: Strip the entire tag, insert @_@ in its place.
Step 3 — Audio/Video extraction: <audio> → itemBody.audio, <video> → itemBody.video. Tags removed from HTML.
Step 4 — Result → itemBody.sentence.text. itemBody.statement = null.

0.4 ID Re-mapping (incremental)

Same rule as FIB and DnD — all IDs are reassigned as sequential integers starting at 1. AAT IDs are used only as lookup keys.

QB FieldAssigned valueAAT lookup source
items[].id 1, 2, 3… by blank-field order in prompt AAT blank-field id attr used to find matching body.blanks.blankItems[] entry
items[].options[].id 1, 2, 3… by order within each blank's choices[] AAT choice id used to resolve correctAnswers[].optionId
correctAnswers[].dropDownId Incremental item id (matches items[].id) AAT validBlankChoices[].blankId → find blank-field position
correctAnswers[].optionId Incremental option id (matches items[].options[].id) AAT validBlankChoices[].choiceId → find choice position within that blank

0.5 Weight Normalization

Same rule as FIB/DnD — divide by 100. 100.0 → 1.0, 50.0 → 0.5. Source: body.blanks.blankItems[].weight.
