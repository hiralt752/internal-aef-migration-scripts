9. Action Required - FIB Migration Analysis

Purpose:

This document contains analysis findings from the FIB dataset migration review. The observations below are based on currently analyzed AAT FIB question data and sample payloads.

9.1 Needs Human Decision

# QB Field AAT Source Question / Concern Current Assumption Analysis
1 itemBody.items[].feedback body.blanks[].feedback Per-blank feedback is currently available as HTML string content. Should this HTML be stripped, sanitized, or copied directly? Direct copy of HTML string The current FIB request schema already contains HTML-based content in other fields such as sentence/prompt rendering.
During dataset inspection, feedback values were observed in HTML format. Since the frontend/request schema already supports HTML rendering in other areas(body.prompt), it may be possible to pass feedback directly without additional processing.

7 itemBody.items[].wirisXml body.prompt (Wiris math) Are there Wiris/math-enabled blanks in the dataset? null There is presence of Wiris XML content.
Questions containing MathML/Wiris structures were found. 
"wirisXml": "<question>
  <correctAnswers>
    <correctAnswer type='mathml'>...</correctAnswer>
  </correctAnswers>
</question>"
8 itemBody.items[].wirisSvg body.prompt (Wiris math) Are SVG-based math blanks present? null There is SVG-based Wiris rendering data. 
"wirisSvg": "data:image/svg+xml;charset=utf8,..."
SVG content appears to represent rendered visual equations associated with Wiris math answers.
Frontend rendering expectations and QB storage requirements should be validated before implementation.
9 itemBody.numberedSentence — Are numbered blank layouts present in the dataset? false No numbered sentence layouts were found during dataset review.
No patterns such as:
  • 1. ___
  • (1) ___
  • ordered blank lists
were observed.
Current findings suggest this flag may safely default to false, although additional edge-case validation may still be recommended.
10 itemBody.centered body.prompt (CSS) Should text-align:center CSS drive this flag? false Dataset analysis found multiple occurrences of: 
text-align: center
However, these occurrences were primarily found in:
  • table cells
  • word bank layouts
  • content formatting
No dedicated center-aligned sentence structure or explicit center-layout metadata was found.
It may be safer to avoid automatically deriving centered=true solely from generic CSS usage without additional UI validation.
11 correctAnswers[].answerInWidgetFormat — Is this field optional? Does QB reject null values? null No widget-format answer structures were found in the analyzed AAT dataset.
Current answer mappings appear as plain values: 
"correctAnswer": "example"
and not structured widget objects such as: 
{
  "value": "example"
}
Additional QB API validation testing is recommended to confirm:
  • whether the field is optional
  • whether null is accepted
  • expected object structure (if required)
12 responseDeclaration.multipleAnswer validation.scoringType / blank count Should multi-blank PARTIAL_MATCH questions enable multipleAnswer? false Dataset analysis found:
  • multi-blank FIB questions
  • PARTIAL_MATCH & EXACT_MATCH scoring types
This suggests the response model supports multiple independent blank validations.
However, it remains unclear whether QB internally treats:
  • multi-blank FIB as composite single response
  • or true multi-answer response handling
API behavior should be validated with implementation testing before finalizing this field behavior.
