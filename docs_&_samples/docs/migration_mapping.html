0.3 Prompt / TIN — Media Extraction from body.prompt

The legacy body.prompt is an HTML string that may contain embedded <img>, <audio>, and <video> tags. These tags are stripped from the HTML and returned as structured objects. The remaining cleaned text is kept separately.

Step 1 — MathML detection: If an <img> has a src starting with data:image/svg+xml and containing MathML, it is a Wiris math formula. It is converted to inline LaTeX (\(latex\)) and stays embedded in the text string. It is NOT extracted as an image.
Step 2 — Image extraction: The first non-math <img src="..."> is extracted → { url: "..." }. The <img> tag is removed from the HTML string.
Step 3 — Audio extraction: The first <audio src="..."> is extracted → { url: "..." }. Removed from HTML.
Step 4 — Video extraction: The first <video src="..."> is extracted → { url: "..." }. Removed from HTML.
Step 5 — Text cleanup: Newlines are converted to <br>. All remaining HTML tags are stripped except <span> and <br>. The result is the clean text.

The extracted parts are then assembled into the itemBody.statement.content[] array (and separately into top-level audio / stemVideo fields):

0.4 Hint-Mapper Logic

Legacy hints (body.hints[]) and incorrect feedback (body.wrongAnswerFeedback) are processed together. The result is split between outcomeDeclaration.feedback.incorrect and modalFeedback.needHelp.

Key concept: feedback.incorrect is shown inline after a wrong answer. modalFeedback.needHelp is shown in a separate "Need Help" modal. The mapper decides which content goes where based on the rules below.
# Condition → feedback.incorrect → needHelp
R1 body.wrongAnswerFeedback has text wrongAnswerFeedback content (text + any media) ALL hints (every hint goes to needHelp)
R2 0 hints AND no wrongAnswerFeedback null / absent empty / absent
R3 1 hint, hint has NO media (image/audio/video), no wrongAnswerFeedback The single hint (text only) empty / absent
R4 1 hint, hint HAS media (image/audio/video), no wrongAnswerFeedback null / absent The single hint (text + media)
R5 2+ hints, no wrongAnswerFeedback Last hint text only First N−1 hints (all content) + last hint's media (if any, text-stripped)

R5 detail: When there are multiple hints and no existing wrongAnswerFeedback, the last hint acts as the "summary" shown inline after a wrong answer (text portion only). All earlier hints, plus any media from the last hint, are surfaced in the NeedHelp modal. This ensures media-heavy hints aren't lost.

Content format: Each item in needHelp.content.content[] is a separate ContentItem object: { type: "text", text: "..." }, { type: "image", image: { url } }, { type: "audio", audio: { url } }, or { type: "video", video: { url } }. Text and media are split into separate array entries.

3.4.1 Hint-Mapper Decision Rules for feedback.incorrect and modalFeedback.needHelp

Both feedback.incorrect and needHelp share the same computed result.

Key distinction: feedback.incorrect is the inline message shown after a wrong answer. modalFeedback.needHelp is the content in the separate "Need Help" modal the student can open.

Inputs: hints = body.hints[] (array of HTML strings) · incorrectFeedback = body.wrongAnswerFeedback (HTML string or null)

Pre-processing: Each hint is parsed to split it into text, image, audio, and video parts. The wrongAnswerFeedback is also parsed; it is only considered "existing" if the extracted text is non-empty.

# Condition (wrongAnswerFeedback / hints) → feedback.incorrect content → needHelp.content.content[]
R1 wrongAnswerFeedback has text
(regardless of how many hints exist) 		wrongAnswerFeedback text + any media from it.
Shown inline as the incorrect feedback. 		ALL hints moved here (every hint goes to needHelp).
Shown only if student opens "Need Help".
R2 0 hints AND no wrongAnswerFeedback null — field omitted empty — needHelp omitted
R3 Exactly 1 hint
Hint has no media (no image, audio, or video)
No wrongAnswerFeedback 		The single hint's text.
(Text-only hint acts as the inline incorrect message.) 		empty — needHelp omitted
R4 Exactly 1 hint
Hint has media (image, audio, or video)
No wrongAnswerFeedback 		null — field omitted The single hint (text + media).
(Media-rich hint goes to needHelp to preserve the media.)
R5 2 or more hints
No wrongAnswerFeedback 		Last hint — text only (media stripped out).
(The final hint is the inline summary.) 		First N−1 hints (all content, text + media)
+ last hint's media (if any), as a text-stripped item.
(Earlier hints + any media from the last hint surface in the modal.)
R5 example: 3 hints — hint 1 (text + image), hint 2 (text only), hint 3 (text + audio).
→ needHelp: [hint1 text item, hint1 image item, hint2 text item, hint3 audio item]
→ feedback.incorrect: hint3 text only.
Content format in needHelp: Each hint is flattened into separate typed objects per media: { type:"text", text:"..." }, { type:"image", image:{url} }, { type:"audio", audio:{url} }, { type:"video", video:{url} }. One hint may produce multiple array entries.

5. Common: modalFeedback

Contains needHelp content and optional passage reference. Uses the hint-mapper result (§0.4). The entire modalFeedback object is omitted from the payload when there are no needHelp items and no passage.

modalFeedback.needHelp.content.layout String YES (if needHelp present) Hardcode — Always "TEXT".
